# BOUNCERS ON TIPS (BOT) 🛡️⚡

> **"Your backup. On demand."**  
> India's first on-demand bouncers & personal security ride-hailing prototype.

---

## 🌟 Overview

**Bouncers on Tips (BOT)** is a next-generation on-demand personal security booking platform. Inspired by the instant dispatch model of Rapido and Uber, BOT enables consumers to request vetted bouncers, female safety escorts, and VIP close-protection squads within minutes across Bengaluru.

---

## 🚀 Key Features

- **⚡ Instant 7-Step Tactile Booking**:
  - **Purpose Selection**: 10 tailored use-cases (*Women's Safety, Personal Protection, Night Out/Clubbing, Party Entry, College Fests, Weddings, Corporate, VIP, Transit*).
  - **Dynamic Squad Sizing**: Interactive stepper with live SVG character avatars preview.
  - **Tier Pricing**: Standard (₹500/hr), Pro Tactical Fighter (₹800/hr), Elite Guard (₹1,200/hr).
  - **Specialized Squad Avatars**: Custom illustrated characters for Female Squad (Women's Safety), Male Bouncers, and Mixed Duos.
  - **Interactive Urban Map**: Draggable pin, Bengaluru landmark suggestions, and instant GPS geolocation.
  - **Flexible Scheduling**: Flexible time window with live end-time calculation.
  - **Transparent Pricing**: Itemized cost breakdown with 8% platform & insurance protection fee.

- **📡 Live Sonar Radar Matching**:
  - Circular sonar sweep gauge pinging nearby units in real time.
  - Live candidate stream showing accepts, declines, and arrival distances.

- **🛡️ Team Confirmed & Security OTP PIN**:
  - 4-digit arrival authentication OTP code (e.g. `4 8 9 2`) for client safety.
  - Assigned captain profile cards with ratings, completed missions, and ETAs.

- **📍 Live Active Tracking & Emergency SOS**:
  - Live dispatch map simulating roaming units.
  - Direct 1-tap **Phone Call** and **WhatsApp Chat** with captains.
  - **Emergency SOS (112)** rapid reaction protocol broadcast modal.
  - Multi-dimensional 5-star rating flow (*Professionalism, Punctuality, Demeanor, Communication*).

## 🏃 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/rachit587/bot.git

# Navigate into directory
cd bot

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Compile optimized production bundle
npm run build

# Start production server
npm start
```
